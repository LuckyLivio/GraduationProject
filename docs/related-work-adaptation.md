# 在线校准近邻文献与可主张的贡献

核验日期：2026-09-17。实际访问了以下 5 篇论文的 arXiv 摘要；对 GrBAL/ReBAL、CaDM、RMA 还查看了 HTML 正文的方法部分，对相关作者代码读取了 README。未运行这些外部实现。访问结果及内容摘要哈希保存在 [literature-check.json](../artifacts/literature-check.json)。这是围绕当前机制的定向核验，**不构成穷尽检索或原创性证明**。

## 先给判断

“学到的动力学先验 + 最近交互历史 + 在线适应”已经是成熟的研究路线；残差模型、上下文适应、阈值触发也不能单独声称首创。当前本科课题值得验证的窄问题是：

> 在固定神经空间动力学先验和相同 MPC 预算下，能否用一个仅依赖过去有效转移的校准门控，在环境未变化时保留预测精度，在动力学变化后及时修正模型，并明确噪声与非整体变化下的失效边界？

暂定题目仍可用 **《面向动力学变化环境的轻量世界模型在线校准与导航规划研究》**。若主实验稳定，再把“变化感知”或“选择性校准”写入题目。贡献应写“设计并评估”，不能预写“提出全新世界模型”或“首次实现在线适应”。

## 1. PETS：学习动力学与在线规划的基础

- **文献**：Kurtland Chua, Roberto Calandra, Rowan McAllister, Sergey Levine. *Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models*. 2018。[论文](https://arxiv.org/abs/1805.12114) · [作者代码](https://github.com/kchua/handful-of-trials)。
- **已有内容**：概率动力学模型集成、轨迹采样传播不确定性、基于模型的规划。神经动力学 + 采样式 MPC 不是本项目的新贡献。
- **与本项目区别**：本项目是含已知运动结构的轻量神经阻尼场、有限历史参数校准与校准门控；当前确定性集成不等于完整 PETS。
- **实验启示**：所有方法共用学习模型、候选采样器与规划预算，才能把变化归于校准机制。集成一致不能证明预测正确，也不能替代真实观测失配信号。
- **复现成本**：原 README 要求 MuJoCo 1.31，适合参考方法；不必为二维任务迁移其全部旧依赖。

## 2. GrBAL / ReBAL：最接近“先验 + 近期历史适应”的工作

- **文献**：Anusha Nagabandi, Ignasi Clavera, Simin Liu, Ronald S. Fearing, Pieter Abbeel, Sergey Levine, Chelsea Finn. *Learning to Adapt in Dynamic, Real-World Environments Through Meta-Reinforcement Learning*. arXiv 初稿 2018；本次方法核验使用 2019 年 v6。[摘要](https://arxiv.org/abs/1803.11347) · [v6 正文](https://arxiv.org/html/1803.11347v6) · [作者代码](https://github.com/iclavera/learning_to_adapt)。
- **已有内容**：用元学习得到可快速适应的动力学先验，使用近期转移进行在线更新。GrBAL 通过梯度更新适应，ReBAL 通过循环模型的隐状态更新适应。
- **与本项目区别**：这里没有元训练、循环网络适应或在线神经权重更新；只校准低维乘法系数，研究是否应该应用这一修正。降低实现复杂度是工程取舍，本身不足以证明算法创新。
- **实验启示**：必须比较“始终校准”和“从不校准”，并评估同一回合内的突然变化。仅在回合开始设置不同阻尼，不能测出真实变化检出延迟。
- **复现成本**：作者代码是 TensorFlow 和 MuJoCo 1.31 环境，提供 GrBAL、ReBAL、非适应 MPC 脚本。短期不迁移整套框架；论文须明确没有声称优于这两种原算法。
- **引用注意**：早期 arXiv 版本使用过不同标题和 RBAC/GBAC 名称；正式引用统一到实际阅读的版本，不混用。

## 3. CaDM：最近经验作为动力学上下文

- **文献**：Kimin Lee, Younggyo Seo, Seunghyun Lee, Honglak Lee, Jinwoo Shin. *Context-aware Dynamics Model for Generalization in Model-Based Reinforcement Learning*. 2020。[论文](https://arxiv.org/abs/2005.06800) · [v2 正文](https://arxiv.org/html/2005.06800v2) · [作者代码](https://github.com/younggyoseo/CaDM)。
- **已有内容**：从近期经验编码局部动力学上下文，再据此预测下一状态；用前向和后向动力学训练目标帮助上下文学习。因此，“给世界模型补一个历史上下文”已有直接先例。
- **与本项目区别**：本项目上下文是可解释的一维系数，靠加权最小二乘辨识，不学习上下文编码器；门控检验的重点是原分布预测保持与适应代价。
- **实验启示**：应说明训练只见名义阻尼场，测试变化是否见过；不能把在多动力学上训练的 CaDM 与只见一个场的模型简单做不等数据比较。
- **复现成本**：README 使用 TensorFlow 1.15、Gym 0.16、mujoco-py 2.0。若后续加入小型历史编码 MLP 基线，应标成“受 CaDM 启发的简化基线”，不能标成已完整复现 CaDM。

## 4. RMA：把适应过程做成可观察的机器人能力

- **文献**：Ashish Kumar, Zipeng Fu, Deepak Pathak, Jitendra Malik. *RMA: Rapid Motor Adaptation for Legged Robots*. RSS 2021。[论文](https://arxiv.org/abs/2107.04034) · [v1 正文](https://arxiv.org/html/2107.04034v1) · [作者项目页](https://ashish-kmr.github.io/rma-legged-robots/)。
- **已有内容**：基础策略与适应模块协同工作；适应模块从状态动作历史预测环境相关的潜在表征。训练阶段使用特权环境信息，部署时根据历史推断。
- **与本项目区别**：RMA 主要适应控制策略，不是本项目的显式动力学模型 + MPC 路线；“机器人根据反馈适应地面/载荷变化”的展示主题也已有代表性作品。
- **实验启示**：可以借鉴“变化发生—适应状态变化—行为恢复”的可解释演示顺序；不能把二维已知运动结构的仿真结果外推成四足机器人实机能力。
- **代码核验**：项目页目前链接 [antonilo/rl_locomotion](https://github.com/antonilo/rl_locomotion)；其 README 明确为基于 RMA 的后续 Cross-Modal Supervision 代码，使用 Raisim，并非原论文版本的无差别替代。

## 5. GP 残差 MPC：物理结构与学习修正并非新组合

- **文献**：Lukas Hewing, Juraj Kabzan, Melanie N. Zeilinger. *Cautious Model Predictive Control using Gaussian Process Regression*. arXiv 初稿 2017；当前 v4 为 2019 年修订。[论文](https://arxiv.org/abs/1705.10702) · [期刊 DOI](https://doi.org/10.1109/TCST.2019.2949757)。本次核验摘要与 arXiv 书目信息，未复核全文证明。
- **已有内容**：把名义物理系统与 GP 学到的非线性加性动力学结合，将剩余不确定性纳入谨慎 MPC，并报告仿真与遥控赛车硬件实验。
- **与本项目区别**：当前是神经空间先验的乘法参数校准，不是 GP 加性残差，也没有机会约束或概率安全保证。用“残差校准”命名时，应给出实际公式，避免误导为通用残差网络。
- **实验启示**：应保留物理辨识基线。模型误差降低、规划成功率提升、可证明安全是三种不同主张，当前只能用实际测量支撑前两种。

## 当前机制的准确表述

设学习得到的阻尼场为 `d_phi(p)`，冻结网络参数 `phi`。用最近 5 条有效转移的加权最小二乘估计尺度 `c_hat`，候选校准模型使用 `c_hat * d_phi(p)`。门控依据持续的 `abs(log(c_hat))` 偏离，阈值只用名义验证数据确定。启用时应用该系数，停用时回到尺度 1。

这是**结构化神经动力学先验 + 在线参数辨识 + 选择性应用修正**。这里的最小二乘、持续阈值和验证分位数都有已有方法背景；可以研究它们在有限历史、空间阻尼和实时导航约束下的组合效果，但不能仅凭这 5 篇文献声称没人做过同类门控。

`abs(log(c_hat))` 测的是参数偏离，不是完整的一步预测残差或校准置信概率。它对整体尺度变化敏感，却可能漏掉非乘法变化。有效转移不足时“不校准”表示证据不足，不能解读成“确定环境没有变化”。

经典序贯检测可进一步参考 E. S. Page, *Continuous Inspection Schemes*, 1954，DOI [10.1093/biomet/41.1-2.100](https://doi.org/10.1093/biomet/41.1-2.100)。本次仅由 Crossref 核实书目，出版社页返回 403，未读原文；不据此给当前门控套用 CUSUM 的理论保证。若后续加入 CUSUM 基线，应单独核验并说明统计量及阈值校准。

## 先做什么实验才能判断值得继续

| 必要对照 | 回答的问题 |
| --- | --- |
| 冻结学习模型 | 环境未变化时，原先验到底有多准确？ |
| 学习模型 + 始终校准 | 不加门控的适应收益与原分布损害各有多大？ |
| 学习模型 + 持续门控校准 | 门控是否降低误修正，同时保持变化后的适应速度？ |
| 相同有效历史的局部物理辨识 | 学到的空间结构是否比纯在线参数估计更有用？ |
| 单次阈值触发，去掉持续条件 | 改善究竟来自选择性修正还是持续性条件？这是下一步消融，不混进当前主实验调参。 |

必须统一有效转移过滤、历史长度、回合重置、初始先验、MPC 时域、候选采样器与模型计算预算。校准额外网络查询和更新时间单独计数并纳入总耗时。物理基线没有神经调用时，同时报告候选轨迹步预算与真实延迟，避免用成员步数字暗示所有方法耗时相同。

建议预先冻结测试面板：无变化；回合内整体倍率突变；变化后恢复；局部空间变化；小幅状态观测噪声。全局倍率变化符合当前模型形式，是能力验证；局部变化和噪声是边界检验。预先写好事件时刻和噪声定义，测试环境真值仅供评分，不能提供给控制器。已看过并用于设计机制的数据应标成探索数据，新的留出种子才用于确认。

至少同时报告：

1. **保持能力**：无变化时的 1/5/16 步预测误差、门控激活步比例、整回合发生过误触发的比例。
2. **适应能力**：真实变化发生至首次触发的控制步数、适应后预测误差、未触发比例；未触发回合不能从延迟统计中删除。变化前已误激活的回合需单列，不能记成零延迟成功。
3. **恢复能力**：动力学恢复后退出校准的延迟、残留错误修正的时长；不支持恢复的门控应明确限制。
4. **闭环表现**：成功率、碰撞率、超时率、到达步数及控制 P50/P95 延迟。成功率有上限效应时，预测改善仍应与任务改善分开写。
5. **统计单位**：按完整回合配对，报告多训练种子。滚动历史窗口重叠，不能把每个时间步都当独立样本；若给区间，应按回合或场景分组抽样。

**关键限制**：名义验证集的单窗高分位阈值不保证整回合误报率；重叠窗口也不满足独立检测假设。持续条件可能减少误触发，但会增加检出延迟，必须测量这一取舍。若只有固定历史长度的窗口评测，就只能报告“窗口内触发率”，不能称为“整回合误报率”。

## 论文中可以怎样写贡献

待实验支持后，可表述为：“针对二维空间阻尼导航，构建可实时运行的结构化学习动力学与 MPC 系统，设计仅使用近期有效转移的选择性尺度校准机制，并通过名义保持、变化响应、恢复及失配边界实验分析其收益与局限。”

若门控在多个训练种子上保持名义预测精度，且变化后仍接近始终校准，可形成明确的本科方法改进证据。若只是整体倍率上有效、噪声或局部变化下失败，仍可写有限适用条件；若只改善预测而没有稳定控制收益，应把论文结论限定为预测与校准机制。导师是否认可创新性需要结合这些具体差异判断，不能由“世界模型”名称代替。
