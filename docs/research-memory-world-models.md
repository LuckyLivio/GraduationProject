# 从阻尼拟合升级到“遮挡下记忆、想象与主动观测”

检索日期：2026-09-17。适用条件：本科毕设、约 10 周、RTX 5080 Laptop 16 GB、现有 Windows / PyTorch 环境。本报告是选题与验证方案，**尚未训练或证明下述新系统有效**。

## 保留导航方向的候选路线

本路线作为保留现有导航系统的备选；本轮综合选题报告优先考虑更直观的对象交互任务。以下方案的优点是可复用导航与回放界面，代价是记忆导航已有非常接近的近期工作，创新论证需要更窄、更严格。

候选题目：**《面向遮挡环境的记忆世界模型与主动观测导航方法研究》**。

把场景改为有货架遮挡的仓库交叉口。机器人先看到一辆横向经过的搬运车，随后车辆进入遮挡区。系统必须记住其历史、预测可能的出口时间和方向，比较“直接穿越、减速等待、向侧方探头”三种行动后果。界面同时显示机器人实际看到的画面、模型内部的障碍概率、不同动作的预测分支，以及执行后的真值回放。

这比当前位置到阻尼的拟合更能体现世界模型的用途：当前观测不足以决策；不同动作会改变未来观测；同一时刻可存在多个可能未来。**不能承诺世界模型一定胜过有记忆的传统方法，更不能宣称能准确看见从未观察过的独立随机事件。** 对未见过的区域应维持不确定性，通过主动移动获得信息。

## 可实现的模型：先让“记住并预测”成立

### 观测与环境

- 自建 2D 仓库模拟器，提供 **64×64 局部栅格图 + 可见性掩码 + 本体运动量 + 目标方向**；遮挡必须经过视线检查，不能把全局真值画入输入。初版可用固定朝向的局部栅格降低定位难度，后续增加旋转视角。
- RGB 是一种编码选择；若使用语义栅格，需要明确是模拟器直接提供的语义感知，不能写成从原始相机完成了感知。后续可增加 RGB 编码器作为独立扩展。
- 生成直行、转弯、停走三类动态目标；一部分运动线索在遮挡前可见，一部分后续分支随机。后者只能预测分布，不能要求模型猜中随机真值。
- 地图、运动意图、观测噪声、初始条件分别用随机种子记录。训练/验证/测试按**整张地图和完整回合**切分，不能随机拆相邻帧。

### 轻量行动条件循环世界模型

`局部图像/栅格 → CNN 编码器 → GRU 确定性记忆 + 随机隐变量 → 行动条件转移 → 未来观测 / 占用概率 / 碰撞风险`。

工程起点：约 3–8 M 参数，GRU 宽度 256，32 步序列，batch 16，混合精度，先试 64×64 输入。这是待测的起始配置，不是本机实测显存或时长保证。若显存紧张，先减 batch/序列长度。100k 帧 uint8 RGB 裸图像约 1.23 GB，含动作、掩码与状态的总数据会更大；按回合分块存储。

训练从 50k–100k 交互步的离线数据开始，混合安全导航、停止等待、短距离探头、随机转向，覆盖决策动作。损失先用未来可见观测重建、奖励/碰撞预测与 KL 正则；增加多步展开检查，避免只会复制前一帧。

隐藏障碍的位置可以有两种严格区分的用途：

1. **只做评价探针**：世界模型依靠观测与动作自监督训练，冻结后训练/评价探针测记忆。这能证明表征保留了什么，但不保证控制器已经用到了它。
2. **模拟器监督训练信念/占用头**：可以提升小数据学习效率，但必须明确训练阶段用了真值监督，并给其他学习基线相同标签预算。部署输入仍只有局部观测；不得把训练标签作为运行时输入。

建议先做第二种工程验证，成功后再比较有无真值辅助损失。论文名称与方法描述应如实写成“仿真监督的记忆世界模型”，不能笼统称为完全自监督。

规划时从当前信念对“通行、等待、探头、绕行”等短动作序列展开 8–16 步，抽取若干随机隐变量样本，用到达进度、碰撞概率、时间与观测价值打分。控制器只能使用模型预测和当前传感信息，不能在候选评估时调用真模拟器的隐藏车辆状态。

## 可验证的创新候选

推荐先检验 **“风险触发的主动观测”**：仅当当前路线与遮挡区域的预测风险相关、且预期新观测能改变行动选择时，支付探头代价；低风险时继续行驶。通过改变可见性来降低决策相关的不确定性。

这仍是**候选改进**，不等于已经证实学术首创。主动感知、信念空间规划、信息增益、模型集成分歧均有长期研究；不能只写一个加权和就宣称重大算法创新。最接近的遮挡/主动感知论文需要纳入主报告的额外定向检索。

可以形成有辨识度的本科贡献：可复现的动态遮挡任务；行动条件循环模型；一个风险相关的观测触发策略；严格消融与失败案例；能看见内部信念变化的系统。性能是否大幅提升必须由新实验回答。

## 必须有的强基线

| 方法 | 解决的问题 | 比较时必须保持的公平性 |
|---|---|---|
| 无记忆反应规划 | 展示遮挡导致的基础困难 | 仅作弱基线，不能只赢它就论证世界模型有效 |
| Kalman / IMM 目标跟踪 + 占据地图 + 风险 MPC | 有记忆、可传播遮挡目标的传统强方法 | 同样局部观测、检测噪声、控制预算；不得故意清空其遮挡记忆 |
| 规则式保守探头 + 跟踪 MPC | 测试主动观测是否只是一个简单规则即可实现 | 使用相同探头动作、时间与风险代价；阈值仅在验证集选 |
| GRU-PPO 或 GRU 模仿策略 | 分离“记忆带来的收益”与“模型规划带来的收益” | 记录环境交互、训练算力与标签预算；若预算不等应明确 |
| 标准 RSSM + 相同 MPC，无主动观测奖励 | 分离世界模型基座与提出的改进 | 相同数据、架构、动作候选、规划预算，仅改变观测策略 |
| 本方法去记忆 / 去随机分支 / 去风险触发 | 检查各组件是否必要 | 一次只移除一个组件，保持其余评估协议 |
| 全局观测 oracle | 给出该任务可达性能的参考 | 明确拥有额外信息，只作为上界参考，不计入公平竞赛 |

## 首轮判定与停止条件

今天可以完成的目标应是“新环境 + 数据采集 + 小网络训练通路 + 不泄露真值的固定回放验证”，不预先承诺完整 RL 收敛。

第一轮先看离线问题：相同当前画面、不同历史的成对回合中，模型能否给出不同且校准的隐藏占用概率；遮挡 0.5/1/2/4 秒后的 ADE/FDE、Brier score / NLL、置信区间覆盖率；随机多分支是否表现为多种可能而不是过度自信的一条线。

然后看导航：相同测试地图/起点/动态事件的配对比较，碰撞率、成功率、通行时间、停车/探头次数、单位风险的效率、推理延迟。最少 3 个训练种子，并按地图/回合做配对统计；不同方法运行同一场景不能算成多个独立样本。

建议 48 小时内设定研究闸门：

- 若模型记不住遮挡前信息，先修复记忆与数据；不继续美化可视化。
- 若传统跟踪 + 简单探头已达到近 oracle 表现，当前任务不支持声称大收益。改查真正存在意图不确定性/多对象交互的场景，或以计算效率/标定改进为较窄目标，不能刻意削弱基线。
- 若只赢无记忆方法、没有赢标准 RSSM 或传统强基线，将结果定位为系统集成与任务分析，不写“重大算法突破”。
- 测试集只用于最后评估。用于选择场景难度、阈值和模型版本的数据属于开发/验证集；不能反复看测试结果再挑成功场景。

最有说服力的演示是一次真实的三分支回放：**模型预测“直走可能撞、等待安全但慢、探头后可提前通过”，执行探头获得新观测，然后修正信念并通过。** 这可以非常直观，但必须同时提供批量结果和失败回放，不预设所有场景都如此。
