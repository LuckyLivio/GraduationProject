# 世界模型毕业设计：一手阅读清单与选型依据

核验日期：2026-09-17。本清单实际访问了下列 arXiv 摘要页和作者／维护机构代码仓库的 README，核对标题、年份、方法定位与安装说明；未安装或运行这些外部项目。它是一份围绕本项目的起步清单，不是穷尽文献综述，也不能证明某项改进具有首创性。仓库主分支会变化，正式实验需固定版本和依赖。

## 先读什么

按智能科学与技术本科、距答辩 10 周的范围，**首周只优先阅读 PETS、Gymnasium 和 World Models**，分别理解概率动力学与规划、环境接口、世界模型概念。其余按需查阅：TD-MPC2 和 DreamerV3 用于相关工作比较，MiniGrid 用于判断离散导航是否适合，DIAMOND 用于了解视觉路线的额外成本。

本项目的可控起点是：从交互数据学习二维环境的状态转移，用模型预测多个候选动作的未来，再选择并执行第一个动作。它属于**状态空间世界模型与基于模型的控制**；不需要先训练视频生成模型，也不要求在毕业设计中复现下列整个框架。

## 1. PETS：主方案最直接的方法来源

- **标题／年份**：*Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models*，2018。
- **一手来源**：[论文](https://arxiv.org/abs/1805.12114) · [作者代码](https://github.com/kchua/handful-of-trials)。
- **核心内容**：用概率动力学模型集成表示不确定性，通过轨迹采样传播不确定性，并配合采样式规划。作者代码提供概率集成、TSinf 传播与 CEM 优化组合的示例。
- **支持本项目的决策**：先做小型动力学集成与 MPC，研究模型不确定性如何影响规划，具备明确的方法依据。可比较单模型、确定性集成与概率集成，而不必先加入复杂视觉编码器。
- **复现门槛**：原仓库依赖旧版 MuJoCo 1.31 和较老的环境栈，直接运行原实验存在兼容成本；README 的旧版授权说明不代表当前 MuJoCo 的授权政策。建议在自己的二维环境与当前 PyTorch 环境中实现一个范围受限的 PETS 思想基线，并清楚标注与原算法的差异。
- **阅读重点**：模型不确定性与环境随机性的区别；多步预测误差；为什么只执行规划序列的第一个动作后重新规划。

## 2. Gymnasium：实验接口与可复现基础

- **标题／年份**：*Gymnasium: A Standard Interface for Reinforcement Learning Environments*，2024。
- **一手来源**：[论文](https://arxiv.org/abs/2407.17032) · [维护方代码](https://github.com/Farama-Foundation/Gymnasium) · [官方文档](https://gymnasium.farama.org/)。
- **核心内容**：为强化学习环境提供统一接口，便于算法与环境互换、测试和复现。
- **支持本项目的决策**：自建连续二维导航环境时采用 Gymnasium 接口，统一观测、动作、奖励、终止与随机种子；控制器必须只接收已定义的观测，不能偷看模拟器内部的真实未来。
- **复现门槛**：基础包安装较轻；MuJoCo、Atari 等环境系列需要额外依赖。只使用自建二维环境时，不必安装全部环境扩展。该库是环境工具，不是世界模型训练框架。
- **阅读重点**：`reset(seed=...)`、`step(...)`、`terminated` 与 `truncated` 的区别，以及自定义环境的空间定义和检查工具。

## 3. World Models：概念与演示方式

- **标题／年份**：*World Models*，2018 年 arXiv 论文。作者代码还给出了 NeurIPS 2018 版本 *Recurrent World Models Facilitate Policy Evolution* 的引用；写参考文献时应选择实际阅读的版本，避免混用标题。
- **一手来源**：[论文](https://arxiv.org/abs/1803.10122) · [作者项目页](https://worldmodels.github.io/) · [作者实验代码](https://github.com/hardmaru/WorldModelsExperiments)。
- **核心内容**：学习环境的紧凑时空表示，并在学习到的模型中支持策略学习和行为决策。
- **支持本项目的决策**：答辩中同时显示“实际环境”与“模型预测的未来”，让世界模型的用途可观察。模型必须从数据学习，不能把手写模拟器直接称为已经训练好的世界模型。
- **复现门槛**：作者实验仓库明确依赖很旧的 Gym 0.9.x，并指出与 Gym 0.10.x 不兼容。适合作为概念和结构参考；迁移这些旧实验并非主方案的前置任务。
- **阅读重点**：表示模型、时序模型和控制器各自解决什么问题；预测画面看起来合理与真正有助于控制是两种评价目标。

## 4. TD-MPC2：连续控制与机械臂备选

- **标题／年份**：*TD-MPC2: Scalable, Robust World Models for Continuous Control*，2023 年预印本，ICLR 2024。
- **一手来源**：[论文](https://arxiv.org/abs/2310.16828) · [作者代码](https://github.com/nicklashansen/tdmpc2) · [项目页](https://www.tdmpc2.com)。
- **核心内容**：在学习到的隐式潜在世界模型中进行局部轨迹优化，并结合价值学习；代码支持状态和像素观测，以及多个连续控制任务域。
- **支持本项目的决策**：世界模型可以服务于规划而不重建整张图像。若以后转向机械臂，可先选一个仿真单任务，而不是扩展到完整多任务机器人系统。
- **复现门槛**：核验时作者 README 对单任务在线 RL 要求 GPU 和至少 12 GB 系统内存，并推荐至少 8 GB 显存；80 任务离线数据方案要求 128 GB 系统内存，317M 模型训练要求至少 24 GB 显存。这些是该仓库的说明，不能推导成本项目的资源需求。不同机器人任务域还有环境依赖兼容成本。
- **阅读重点**：潜在动力学、奖励／价值预测和 MPC 如何协作；先观察默认单任务配置，不以最大模型为毕业设计目标。

## 5. DreamerV3：通过想象轨迹学习策略

- **标题／年份**：*Mastering Diverse Domains through World Models*，2023 年 arXiv 预印本。当前作者仓库引用的正式版本为 *Mastering diverse control tasks through world models*，Nature，2025。
- **一手来源**：[预印本](https://arxiv.org/abs/2301.04104) · [作者代码](https://github.com/danijar/dreamerv3) · [正式版本](https://www.nature.com/articles/s41586-025-08744-2)。正式期刊页访问时返回站点校验页，2025 年正式版本的标题与年份由作者仓库的引用项核对。
- **核心内容**：从经验学习世界模型，在想象轨迹中训练 actor-critic 策略；与每一步直接做 MPC 的主方案存在方法区别。
- **支持本项目的决策**：论文相关工作可以区分“模型辅助规划”和“在模型中训练策略”。若希望增加强化学习对照，应先明确它与主方案解决的问题和交互预算是否一致。
- **复现门槛**：当前仓库自述为 DreamerV3 的重新实现，要求 Python 3.11+，使用 JAX，已测试的平台为 Linux 和 Mac，默认尝试使用 GPU。Windows 开发机需要另行安排兼容环境，不能假设开箱即用。不同任务的训练成本差异很大，这里不承诺固定显存或训练时长。
- **阅读重点**：想象 rollout 的训练用途；模型误差对策略学习的影响；为什么强基线不等于毕业设计必须整体复现的系统。

## 6. MiniGrid：轻量离散导航备选

- **标题／年份**：*Minigrid & Miniworld: Modular & Customizable Reinforcement Learning Environments for Goal-Oriented Tasks*，2023。
- **一手来源**：[论文](https://arxiv.org/abs/2306.13831) · [维护方代码](https://github.com/Farama-Foundation/Minigrid) · [官方文档](https://minigrid.farama.org/)。
- **核心内容**：可定制的目标导向二维网格与三维环境；MiniGrid 提供离散动作、障碍、钥匙／门及任务描述等机制。
- **支持本项目的决策**：如果连续动力学与规划工作量偏大，可以缩小为离散网格导航。其动态障碍任务也可作为环境设计参考。
- **复现门槛**：环境本身轻量，可通过 `pip install minigrid` 安装；当前 README 支持 Python 3.10+ 的 Linux／macOS，不正式支持 Windows。环境容易运行不代表任意 RL 算法都容易训练。
- **适用边界**：离散网格不等同于带惯性、滑移的连续二维导航。选择它时需要相应调整动作空间、规划器和实验假设。若障碍运动含随机性，预测应允许分布或误差，而不是要求逐帧准确。

## 7. DIAMOND：视觉世界模型备选

- **标题／年份**：*Diffusion for World Modeling: Visual Details Matter in Atari*，NeurIPS 2024。
- **一手来源**：[论文](https://arxiv.org/abs/2405.12399) · [作者代码](https://github.com/eloialonso/diamond) · [项目页](https://diamond-wm.github.io/)。
- **核心内容**：使用扩散世界模型训练强化学习智能体，研究视觉细节如何影响策略；作者同时提供可交互的预训练世界模型演示入口。
- **支持本项目的决策**：如果希望走“可玩的预测未来”视觉路线，先评估预训练模型的交互与误差，再决定是否值得投入训练。演示预训练模型本身不能作为自己的算法贡献。
- **复现门槛**：作者提供 Python 3.10 安装流程、`src/play.py --pretrained` 演示和 CUDA 训练命令。视觉生成、策略训练、环境配置与数据处理的工作量均高于低维动力学；README 没有给出足以在此承诺通用训练时长或最低显存的依据。
- **阅读重点**：视觉质量与决策质量的关系；动作条件下的预测；滚动生成误差；使用预训练模型与从头训练的工作量差异。

## 如何从这些文献形成自己的研究问题

一个可检验的问题是：**在相同交互数据和规划计算预算下，仅利用模型集成的不确定性调整规划视野，能否改善二维动态导航在未见动力学条件下的成功率与碰撞率？** 主研究固定风险惩罚及其他代价权重，避免同时改变多个机制而无法解释效果来源。

这是一项待实验验证的假设，并非上述论文已经证明的结论。尤其需要避免三个跳步：

1. **集成分歧不是天然校准好的置信度。** 应检查其与真实预测误差的关系；集成成员可能在分布外一起预测错误。
2. **更短时域不必然更安全。** 时域缩短可能看不到远处障碍，应与固定短／中／长时域和计算预算匹配的方案比较。
3. **预测误差下降不必然提高任务表现。** 除一步／多步误差外，要测成功率、碰撞率、到达步数、规划延迟和环境交互量，并报告多个随机种子的结果。

主方案首先需要可靠实现的是：自建环境、交互数据采集、学习动力学、固定时域 MPC 和评估流程。随后只选择一个改进点做充分消融。视觉编码、Dreamer 策略学习和机械臂仿真均可作为后续分支，不应同时成为首版验收要求。

正式开题前，还需针对“uncertainty-aware MPC”“adaptive planning horizon”“model-based navigation”等关键词补充近邻工作检索，与导师确认差异点。当前清单只支持方向选择，不能据此写“首次提出”或“优于现有方法”。
