# 毕业论文主方案：预见·Foresight Lab

> 状态：选题与实验设计草案，尚无实测结果。面向智能科学与技术专业本科毕业论文，距离答辩约 10 周。前 2 周跑通最小闭环，第 6 周冻结主实验，第 8 周完成初稿，第 9—10 周修订与答辩。所有像素、部分可观测、在线训练扩展均不进入本轮计划。

## 1. 暂定题目与研究边界

**统一暂定正式题目：基于世界模型不确定性估计的动态环境自适应规划方法研究**

**工程版题目：基于轻量世界模型的智能体预测与规划系统设计与实现**。若导师更重视系统完成度，或自适应方法未显示稳定优势，采用工程版更稳妥。

展示名称为 **预见·Foresight Lab**，主题是“会判断该想多远的导航智能体”。题目中的不确定性估计具体指模型集成分歧及其经验可靠性检验，不暗示已经得到校准的概率或安全保证。

研究问题是：在**控制器不知道真实阻尼函数、且测试时阻尼强度可能变化**的环境中，学习到的动力学模型在不同场景、不同预测步长上的可靠程度不同；是否可以利用这种差异，在有限推理预算内动态选择模型预测控制（MPC）的规划视野，使智能体在导航成功率、安全性和实时性之间取得更好的折中？主研究机制只选“可靠性驱动的视野选择”；候选数变化是保持预算相同的配套措施。

**世界模型的核心必须是从交互数据学习的动作条件动力学模型**：输入当前状态和候选动作，预测未来状态，规划器在该预测模型中比较不同动作序列，再把选出的动作执行到真实仿真环境。仿真器只负责生成训练数据、执行动作和评测；规划器不能调用仿真器的未来状态接口来冒充学到的模型。

主线范围：

- 一个二维连续状态导航环境：单智能体、固定目标、3 个运动障碍物、矩形边界。
- 低维运动状态输入，学习包含未知空间阻尼的状态转移；无须从像素训练大型视频模型。
- 小型动力学模型集成、随机射击 MPC、自适应预测视野。
- 以验证集上的误差统计约束模型使用范围；主要贡献是一个规划机制和可复现实验。
- 不把大语言模型、因果发现、多智能体、三维重建、机器人实机同时纳入主线。世界模型不等同于大参数模型，“因果”也不能仅凭支持动作条件预测就宣称已经解决。

## 2. 可检验的研究假设

| 假设 | 支持它所需的证据 | 可能的否定结果 |
|---|---|---|
| H1：预测可靠性随场景和步长变化，固定视野存在局限。 | 分预测步长的误差曲线；近障碍、速度变化、分布外动力学等场景的分组统计。 | 不同场景差异很小，或模型误差对闭环性能影响很弱。 |
| H2：经验证集检验的集成分歧信号能够辅助识别不可靠的远期预测。 | 分歧与实际滚动误差之间的排序相关性、分箱误差、可靠性阈值的覆盖统计。 | 模型成员共同出错，分歧很小但误差很大；阈值无法泛化。 |
| H3：在相同预测计算预算下，自适应视野优于合理调优的固定视野方案。 | 相同模型调用预算和同硬件延迟约束下的配对评测；成功率、碰撞率和到达效率的折中。 | 优势只来自额外计算、额外调参，或只在个别随机种子上出现。 |

H3 不成立也可以形成完整论文：报告哪些环境条件支持或不支持自适应规划，解释集成分歧的局限，给出适用边界。不能提前写“显著提升”或编造实验数字。

## 3. 环境、状态、动作与观测

### 3.1 第一阶段：低维运动状态

采用长度、速度和时间统一归一化的二维连续环境。参考实现可设控制频率为 10 Hz，单回合最多 200 步；地图大小、障碍半径和速度上限都写入配置，不在论文中把默认值当作唯一设置。

状态定义：

$$
s_t=[p_t,v_t,g,\{p^i_t,v^i_t,r_i\}_{i=1}^{3},b],
$$

其中：

- $p_t,v_t$：智能体二维位置与速度；目标 $g$ 在回合内固定。
- $p^i_t,v^i_t,r_i$：第 $i$ 个障碍物的位置、速度和半径。
- $b$：已知地图边界；智能体半径为固定配置参数。
- 动作为归一化二维加速度 $a_t\in[-1,1]^2$，由环境施加加速度上限、速度上限及惯性/阻尼。

运动状态完全可观测，$o_t=s_t$ 是主实验设定；**这不表示真实转移方程或阻尼参数已知**。模型实际上只预测动态部分 $x_t=[p_t,v_t,\{p^i_t,v^i_t\}]$，目标、边界和物体半径作为条件输入或静态上下文传递。

主变量只选**空间变化的阻尼**。例如，真实环境使用 $v_{t+1}=\operatorname{clip}((1-d_\theta(p_t)\Delta t)v_t+\alpha a_t\Delta t)$，$p_{t+1}=p_t+v_{t+1}\Delta t$；$d_\theta(p)$ 是平滑、有界的空间阻尼场。精确函数、场的参数及其查询接口不提供给学习规划器。智能体必须从交互数据学习不同区域的运动响应。该设定比完全已知的匀速导航更能检验学习模型的必要性，但最终仍要用物理基线验证，而不能预设学习一定更好。

同分布训练、验证和测试使用同一个固定阻尼场与不同初始场景，保证运动状态对转移预测足够；分布外评测**只改变阻尼场的整体强度**，其余因素保持匹配。所有模型可以读取最近 5 步的低维观测与已执行动作，供物理基线在线辨识阻尼，也供小型 MLP 使用；回合开始的缺失历史用掩码标明。第一版障碍采用确定性的匀速运动与边界反弹，不再叠加未知执行延迟和随机障碍模式。

环境要允许出现“短期直走看起来安全、再向前会遇到横穿障碍”的情形，否则研究预测视野的意义很弱。主结果建立后才考虑其他动力学扩展。

注意：如果加入按隐藏计时器触发的运动切换，当前状态可能不再满足马尔可夫假设。应把相位等必要变量纳入观测，或将其明确归入部分可观测扩展；不要让遗漏变量被误解释成模型方法失败。

### 3.2 明确后置的工作

局部观测、GRU、像素世界模型、可变数量障碍和在线神经网络训练均不做。当前提供低维运动状态，不能包装成“仅凭视觉理解世界”。短历史输入只是已观测的状态动作窗口，不引入新的感知系统。

### 3.3 奖励、约束与碰撞

规划代价由预测状态计算，至少包含目标距离、碰撞惩罚、边界惩罚和动作变化代价：

$$
J=\sum_{k=1}^{H}\left(w_g\|\hat p_{t+k}-g\|_2+w_c C(\hat s_{t+k})+w_b B(\hat s_{t+k})\right)+w_u\sum_{k=0}^{H-1}\|a_{t+k}-a_{t+k-1}\|_2^2.
$$

碰撞检测使用智能体与障碍物的相对运动线段最小距离，避免障碍在两个离散采样时刻之间穿过智能体却被遗漏；发生边界反弹的时间步按反弹时刻拆成子线段。到达目标、碰撞、超时分别记录为终止原因。预测状态中几何相交不是经过校准的“碰撞概率”。

奖励/代价函数可以手工定义，动力学必须学习。此范围内没有必要再学习奖励模型；也不应因为使用手工奖励就把系统称为“非世界模型”。

## 4. 数据采集与防泄露拆分

### 4.1 训练数据来源

第一版目标为约 2 万条状态转移，验证可学习性；正式规模根据收敛情况扩充到约 5 万—20 万条。此处是采集预算，不是已经获得的数据量。

采集策略混合：平滑随机动作、向目标移动的简单控制器、近障碍绕行与制动轨迹。动作应有时间相关性，避免完全独立的随机动作导致几乎不移动。保留接近碰撞和碰撞前的状态，避免数据全来自空旷区域。数据生成器可以使用真实环境状态构造初始场景，但记录每条轨迹使用的策略和场景配置。

只做离线学习与固定数据集评测。第 4 周之后冻结采集策略，全部学习型基线使用相同数据和训练得到的模型；不临时加入在线神经网络更新分支。

### 4.2 拆分顺序

1. 先按**完整环境实例/回合种子**划分训练、验证、测试集合，例如 70% / 15% / 15%。同一轨迹及其相邻窗口只能属于一个集合。
2. 再在训练轨迹中抽样一步和多步训练片段。归一化统计量只用训练集计算。
3. 模型规模、视野阈值、代价权重和基线参数只在训练/验证集选择。测试集合用于最终评估，不能反复看测试表现调参。
4. 另建明确的分布外测试集，主线只改变阻尼场强度；提前写清变化幅度，不能把普通新随机种子直接叫作分布外。
5. 保存数据 manifest：场景 ID、随机种子、动力学参数、采集策略、代码版本及 split。若从同一地图模板生成高度相似场景，可按模板族分组拆分，另外标注哪些测试只考察新轨迹。

测试时各方法使用相同的初始位置、目标、障碍轨迹和外生随机扰动序列，实现配对比较。为避免不同动作导致随机数消费次数不同，障碍运动扰动应预生成，或使用与智能体控制独立的随机数流。

## 5. 学习世界模型与接口

### 5.1 最小可行模型

使用 3 个独立初始化和重采样训练的小型 MLP，输入归一化的当前状态、最近 5 步状态动作窗口及候选动作，输出动态状态增量 $\Delta x_t$。建议先尝试 2 层、每层 128 个隐藏单元；这些是可调起点，不预设最优值。第一周先用单步输入跑通，第二周统一窗口接口；无须 GRU。

一步训练损失为各动态量标准化后的均方误差；模型滚动稳定后，再增加 3—5 步短滚动损失。把位置、速度归一化或分别加权，防止某一量纲主导训练。应报告**开环多步误差**，不能只用一步误差证明模型可用于规划。

障碍物顺序保持固定并记录 ID，暂不使用会随距离排序而导致身份跳变的输入编码。训练批次按轨迹或场景重采样比仅重采样相邻单步更能保留集成多样性，但集成多样性仍不自动代表正确的不确定性估计。

### 5.2 规划器与真实环境的隔离

建议接口如下：

```python
class LearnedWorldModel:
    def predict_next(self, histories, actions):
        # 返回每个模型成员的下一状态预测：[M, batch, state_dim]
        ...

    def rollout(self, initial_histories, action_sequences):
        # 每个成员在自己的预测状态上递推
        # 返回 [M, batch, horizon + 1, state_dim]
        ...

class MPCPlanner:
    def act(self, observation_history, model, budget):
        # 返回 action 和日志：horizon、model_steps、latency、disagreement
        ...

class NavigationEnv:
    def step(self, action):
        # 只在执行真实动作时推进环境
        ...
```

集成滚动应让每个成员沿自己的轨迹递推，更新各自的历史窗口；不能每一步先平均状态再宣称得到了充分的多步不确定性。部署时规划器只接触观测历史、静态地图信息和学习模型；真实环境动力学模块不作为它的依赖。

## 6. 从固定 MPC 到自适应视野

### 6.1 先跑通固定视野规划

最小规划器采用**随机射击 MPC**：采样平滑动作序列，在学习模型中展开，对各集成成员分别计算代价后取平均，选取平均总代价最低的序列，只执行第一个动作，下一控制周期重新规划。固定与自适应视野使用同一个代价聚合方式，不额外给其中一种方法添加风险惩罚。上一周期的最佳序列移位后作为候选和采样中心，减少抖动。

候选视野集合可从 $\mathcal H=\{5,10,15,20\}$ 开始。如果控制周期为 0.1 秒，它们对应 0.5—2 秒预测。集合、候选数和权重都在验证集调优。CEM 可作为后续统一升级，但不能只给提出方法换更强的搜索器。

### 6.2 用预测分歧提供可靠性信号

对一条候选动作序列，第 $k$ 步的集成分歧可定义为各模型成员预测的智能体与障碍位置/相对位置的标准化方差。分别观察智能体、障碍物和相对距离误差，避免将无关变量方差直接相加后失去解释性。

**集成方差只是预测分歧信号，既不等于误差，也不等于校准后的概率。**所有成员都缺少某类数据时，可能一致地预测错误；随机扰动带来的不可约误差也不一定由模型成员分歧反映。

在验证集真实轨迹上，统计“分歧、步长、实际误差”的关系：

- 报告分歧与实际位置误差的 Spearman 排序相关性，按步长分别计算。
- 将分歧分箱，展示每箱实际误差的中位数和高分位数。
- 选定导航可接受的位置误差 $\epsilon$，使用验证集上的误差超限比例选择分歧阈值 $\tau_k$。样本稀疏的分箱合并，或保守禁用该步长。
- 在留出的测试数据上报告阈值实际覆盖情况。这里只能称为经验可靠性检验；在未经分布假设和严格校准前，不能称为安全保证、置信概率或保证覆盖率。

若分歧与误差关系很弱，保留该负结果，优先改进数据覆盖和模型，而不是强行使用概率措辞。可选的概率输出模型需要额外评估 NLL、覆盖率与区间宽度，不作为主线硬要求。

### 6.3 具体的自适应算法

每个控制周期采用两阶段预算分配，保证方法可以直接实现：

1. **探测阶段**：用上一周期移位计划、朝目标的初始计划及少量随机扰动，组成固定的少量候选；在学习模型中滚动到 $H_{\max}$。探测消耗计入本周期总预算。
2. **视野选择**：对每个预测步长统计探测候选的分歧高分位数。选择满足全部前缀可靠性阈值的最长 $H\in\mathcal H$；若全部失败，使用最短视野并记录“可靠性阈值失败”。高分位数及阈值只在验证集调优。
3. **搜索阶段**：把剩余预算分给该视野下的动作序列搜索。短视野可评估更多候选，长视野评估更少候选。探测阶段与最终候选之间可能存在分布差异，因此最终候选仍需记录自身分歧，并报告视野选择后误差。
4. **执行阶段**：只执行最优序列的第一个动作，下一控制周期重复。主实验每一步都重新规划，避免把规划频率变化、执行多步动作和视野变化同时混在一起。

最小失败控制采用统一规则：若所有候选都预测将碰撞或出现数值异常，则执行限幅制动动作，并记录触发次数。所有 MPC 基线使用相同规则；该规则不读取真实阻尼函数，也不宣称能保证避免碰撞。在横穿障碍中专门统计“缩短视野后碰撞”的案例，检查不可靠远期预测与短视风险之间的冲突。更复杂的可达集、控制屏障函数或安全盾不属于本方案必做内容。

这是一个待验证的控制启发式。远期更不确定时缩短视野可能改善模型偏差，也可能使智能体错过即将出现的危险，因此需要专门的横穿障碍场景检验，不能先验声称“更安全”。

如果论文需要“实时计算分配”作为贡献，应在相同预算下比较不同候选数与视野的分配效果，并检验延迟上限。没有这部分证据时，题目使用“自适应规划视野”更准确。

## 7. 基线与公平计算预算

### 7.1 主基线

| 方法 | 用途 | 公平性要求 |
|---|---|---|
| 简单目标趋近 + 局部避障控制器 | 建立没有预测模型的应用参照。 | 不作为证明所提模型最先进的依据。 |
| 简单运动学模型 + MPC | 障碍使用常速度外推；机器人保留动作加速度响应，阻尼设为固定简化值。 | 共用代价、动作搜索与控制频率，报告较低计算成本；纯粹与动作无关的常速度模型只用于预测误差基线，不能用于选择动作。 |
| 固定参数物理模型 + MPC | 强基线：用训练数据拟合单个全局阻尼和动作增益，检查简单系统辨识是否已解决问题。 | 参数拟合只使用训练数据，固定视野在验证集选择；同时报告匹配搜索规模与匹配实际延迟两种比较。 |
| 短历史阻尼辨识 + 物理 MPC | **必须做的强基线**：用最近 5 步状态和已执行动作，估计局部阻尼后规划。 | 与学习模型获取相同历史；辨识耗时计入规划耗时，不读取真实阻尼场。 |
| 学习模型 + 各个固定视野 MPC | 观察短视野和长视野的折中。 | 使用相同训练数据、模型集成、代价、采样器与重规划频率。 |
| 验证集选出的最佳固定视野 MPC | 提出方法最重要的比较对象。 | 预先用验证集选定，不能在每个测试回合事后选择最好视野。 |
| 相同平均视野的随机/预定视野方法 | 判断收益是否来自可靠性信号。 | 按验证集上自适应方法的视野分布采样；随机数独立，统计相同预算。 |
| 自适应视野 MPC | 待检验方法。 | 包含探测、选择与搜索全部开销。 |

短历史辨识可对最近窗口拟合 $v_{j+1}-v_j-\alpha a_j\Delta t\approx-d_t v_j\Delta t$，用带小正则的最小二乘求局部 $d_t$，限制在事先规定的合理范围；动作增益 $\alpha$ 从训练集拟合。低速度或速度截断造成不可辨识时回退到训练集全局估计。它只使用过去数据，规划时按估计阻尼固定外推。必须报告该基线；若它已经足够好，就不能宣称神经世界模型不可替代。

可选：精确真实动力学 oracle 只作拥有额外信息的性能参考上界；有限搜索下不是数学意义的保证上界。10 周内可以不做，不影响主线完整性。

### 7.2 两种预算都要检查

**模型计算预算**：以“一个模型成员对一个候选状态做一步预测”为一个逻辑单位。集成规模为 $M$、候选数为 $N$、视野为 $H$ 时，单轮搜索约消耗 $MNH$ 单位；若使用多轮 CEM，累加每轮开销。自适应方法的探测开销 $C_{\mathrm{probe}}$ 同样计入：

$$
N_H=\left\lfloor\frac{B-C_{\mathrm{probe}}}{MH}\right\rfloor.
$$

固定视野方法获得完整的相同总预算 $B$，而不是人为扣除它并不需要的探测开销。自适应方法不能同时减少视野、增加候选数却声称和原先固定候选数的基线计算量相同。全部方法保留相同集成规模，除非正在做集成规模消融。

**实际延迟预算**：模型调用数相同不等于耗时相同。记录同一设备、相同数值精度与批处理设置下的单步规划时间、中位数、P95、最大值和控制截止时间超限率。GPU 计时需要同步并剔除一次性的预热；报告是否包含数据传输和其他规划开销。

建议先用固定调用预算完成主实验，再用验证集调出满足相同延迟上限的一组配置，进行实时性验证。最终用成功率—调用量、成功率—P95 延迟曲线呈现折中；若实际延迟无优势，应如实限制结论。

## 8. 评价、实验矩阵与消融

### 8.1 场景矩阵

- 空旷/低密度：检查模型控制器能正常到达，不会因过度保守频繁停滞。
- 横穿障碍：检验是否能提前减速、绕行，突出预测的作用。
- 不同障碍速度与拥挤程度：在训练范围内按预定分组评测。
- 动力学偏移：只改变空间阻尼场强度，检测不确定性信号失效；不同时改变障碍速度和执行延迟。

主线先做 3 个场景组、每组约 100 个固定测试回合；学习模型使用至少 3 个独立训练随机种子。资源允许再增加到 5 个种子。该数量是计划值，正式实验应报告最终采用的数量及原因。

### 8.2 必报指标

1. **任务与安全**：成功率、碰撞率、超时率、最低障碍净距离、近碰撞比例。
2. **效率**：成功回合到达时间、路径长度、动作变化量；失败回合单独报告，避免仅展示成功子集而掩盖代价。
3. **计算**：每步模型预测单位数、规划时间中位数与 P95、截止时间超限率。
4. **模型**：1/5/10/20 步开环位置与速度误差，按智能体和障碍分别报告；分歧—误差关系及阈值覆盖。
5. **机制**：视野选择直方图、随场景变化的视野曲线、可靠性阈值失败次数。

各方法在相同测试回合上配对比较。汇总每个训练种子的结果，并给出跨种子的变化；需要置信区间时按“训练种子—场景回合”分层自助抽样，避免把每个控制步都当作独立样本。3 个训练种子下结论仍应克制；不能只挑最好的一次。

### 8.3 优先级明确的消融

**必须完成**：

- 固定视野 vs 自适应视野：预算匹配。
- 真实分歧信号 vs 打乱/随机信号：检验信号是否提供额外信息。
- 计入探测预算 vs 忽略探测预算的成本审计：正式结论只采用前者，后者仅说明错误评估可能产生的偏差。
- 不同步长阈值设置的敏感性：只选择少量合理设置，避免无边界调参。

**最多再选一项**：单模型 vs 3 成员集成，或一步训练 vs 短多步训练。第 6 周后不增加消融分支；像素、局部观测和在线神经网络训练不做。

## 9. 第一周的 go / no-go 检查

第一周结束时应得到真实可运行的最小闭环：

- 环境能批量重放固定种子，碰撞与终止条件通过边界样例检查。
- 采集、按回合拆分、训练、评估、导出曲线全过程只需明确命令，配置和随机种子可保存。
- 学习模型在留出验证数据上优于简单“保持当前位置”的无运动基线，并与常速度模型、固定阻尼物理模型比较；第二周补齐短历史阻尼辨识基线。若物理模型始终足够，应缩小学习模型价值的论断，而不是隐藏该基线。
- 固定视野 MPC 能完成预先指定的一批导航回合，并有真实预测轨迹叠加可视化；规划过程中确认没有调用真实未来转移函数。
- 测到当前机器的训练耗时和单步规划延迟，确认 10 周预算是否合理。

**继续自适应主线**：模型明显学到了动作响应与空间阻尼变化，固定 MPC 可稳定工作，长短视野存在可观察的任务差异，分歧与误差至少显示可研究的关系。

**调整后继续**：若模型滚动失败，先简化障碍动力学、增加数据覆盖和短多步训练；若 CPU 规划慢，减小候选数、模型宽度和最大视野。把随机运动扩展推迟。

**收缩选题**：到第 2 周仍无稳定闭环，则转为“动态导航中学习动力学模型的多步误差与规划性能关系研究”，保留学习模型、固定 MPC、公平实验和可视化，不再承诺自适应机制优于基线。不要靠把真实仿真器接回规划器制造成功演示。

## 11. 算力分档与降级路径

| 资源 | 合理实现 | 优先降级方式 |
|---|---|---|
| 普通笔记本 CPU | 低维状态、3 个小 MLP、向量化环境和批量候选预测；训练时间以第一周实测为准。 | 减小宽度、候选数、最大视野和数据规模，保留预算公平性。 |
| 单张消费级 GPU，约 6—12 GB 显存 | 批量训练与集成滚动，更方便运行多训练种子。 | 维持低维主线，增加实验重复性，优先于增加模型规模。 |
| 已确认可用的单卡约 16 GB 显存 | 默认采用轻量 MLP 集成，批量运行候选轨迹与多训练种子。 | 优先提高实验重复性；显存充足不代表训练时间已验证。 |
| 更强 GPU / 可借用服务器 | 更多独立种子和误差分组。 | 不因算力富余直接改成大视频模型训练项目。 |

建议软件栈：Python、PyTorch、NumPy，环境可遵循 Gymnasium 风格接口，图表使用 Matplotlib，交互演示可用浏览器 Canvas 或简单桌面渲染。具体版本在实现时锁定。低维 MLP 不要求额外购买云算力；任何训练时长和帧率都以目标设备实测为准。

最低可交付版本包含：一个环境、一个学习动力学模型集成、固定与自适应 MPC、配对实验日志、真实数据生成的图表、一个能离线播放的演示。UI 美化不能替代模型训练和实验。

## 12. 论文建议结构

1. 绪论：动态环境导航、有限预测预算与研究问题。
2. 相关工作与基础：学习动力学/世界模型、基于模型控制、模型集成及不确定性局限。
3. 系统与问题定义：环境、状态动作空间、数据拆分、模型与规划器接口。
4. 方法：预测可靠性评估、探测候选、自适应视野和预算分配。
5. 实验：预算匹配基线、主结果、消融、分布外与失败分析。
6. 总结与展望：证据支持的结论、误差来源、局部观测等下一步方向。

论文要明确区分工程实现、实验观察和方法贡献。如果自适应规则属于已有思路的任务化改进，应按实际程度写“设计与验证”，不要未经文献检索宣称首创。

## 13. 答辩展示：把智能体的预测直接展示出来

用同一个固定场景并排播放“固定短视野”“固定长视野”“自适应视野”三个智能体，附上相同预测计算预算。界面展示真实障碍、当前目标、候选路径、选中路径和几条集成预测轨迹；右侧显示当前视野、模型调用数与实际延迟。

推荐演示流程：

1. 空旷区接近目标，观察规划与模型预测正常运行。
2. 横穿障碍出现，观察不同视野的预测轨迹和控制动作。
3. 切换到预设的动力学偏移场景，展示集成分歧的变化及一次失败案例。
4. 展示全部固定测试场景的统计图，解释演示个案和总体实验的关系。

集成轨迹带或颜色深浅标注为“模型分歧”，不要标为“95% 安全区域”。演示必须调用训练得到的模型或播放保存的真实实验日志，不能在前端写死绕障路线。交互改变障碍位置后产生的是新的演示场景，其表现不应混入预先冻结的测试结果。

让人眼前一亮的点应来自：**观众能看到智能体预测的多个未来、它为什么改变预测视野，以及这种决策在相同计算预算下是否有效。**这可以同时形成可展示系统和有明确证据链的毕业论文。
