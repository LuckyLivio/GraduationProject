# 推物世界模型：接下来先证明什么

2026-09-17。路线规划，**不代表以下实验已经完成**。当前已完成的证据见[首轮结果](pushing-pilot-findings.md)。总体顺序是：先让未来预测可靠，再证明主动试探有用，最后完成视觉输入和演示。

用户希望看到明显的智能能力差异。可展示的目标是：**面对同样外观、不同运动响应的箱子，机器人先比较不同推法的后果，只在需要时试推，再调整行动。** 世界模型、历史记忆和主动试探各自都已有先例；本项目的候选贡献是任务相关的试探选择，是否有价值要由对照实验决定。

## 第一阶段：验证长期推演能不能修好

首轮历史模型的一步预测优于相近容量无历史模型，但十步误差没有改善，且在线物理辨识更准确。现在直接升级场景和美术，会掩盖而不会解决这个问题。

下一轮只比较训练目标。保持原来的 24,000 条训练转移及三个模型种子 17/29/43，对每个已经训练好的历史模型复制两个分支：

| 项目 | 匹配继续训练对照 | 多步训练 |
|---|---|---|
| 起点 | 同一已训练权重 | 同一已训练权重 |
| 每次采样 | 同一批五步连续窗口，batch 256 | 完全相同的窗口 |
| 输入下一步 | 当前步真实状态（teacher forcing） | 上一步模型预测状态 |
| 监督 | 每一步的世界坐标位置、角度和速度 | 相同监督、相同权重 |
| 历史信息 | 固定为窗口开始前最多六次真实转移 | 完全相同，展开时不更新 |
| 预算 | 2,000 次更新、每窗口五次前向 | 相同更新数和前向数 |
| 权重选择 | 只根据原验证集十步指标选取，包含初始权重 | 完全相同 |

这样能分清改善来自“多训练了一会儿”“换了验证选择标准”，还是来自模型真正学习承受连续预测中的误差。两个分支都应从独立且相同初始化状态的优化器开始，使用对应的采样序列。五步反向传播的计算图更大，所以相同前向次数不等于相同训练时间或显存；这些成本要单独记录。

新开发评估使用预定的 80 个场景，种子从 91000 开始，一半参数范围内，一半范围外。它用于这次开发判断，不替代最终论文保留测试集。不得用这些场景重新挑选 checkpoint、修改损失权重或筛选获胜例子。位置误差、角度误差必须同时报告，并按范围内／范围外拆分。三个模型在同一场景上的结果不是三个独立场景；统计不确定性时先在场景内汇总种子，再按场景做配对分析，同时列出各训练种子的方向。

**本轮的继续门槛**：按照[第二轮冻结协议](pushing-multistep-protocol.md)，相对匹配继续训练对照，十步位置 RMSE 降低至少 20%，按场景配对、先平均训练种子的探索性 95% 差值区间完全低于零，同时一步平均位置 RMSE 的相对恶化不超过 10%。这是预先声明的开发决策门槛，不是论文创新成立的证明。逐个种子及参数范围内／范围外的结果均需报告；角度退化也应检查，但不另加为本轮预注册硬门槛。范围外未改善时，要明确收窄结论；若不通过，先检查旋转累积、接触状态表示和训练动作覆盖，最多做一个有依据的修复阶段，再决定是否保留这条路线。

随后在预定的 12 个新规划场景上比较全部三个训练种子，保留物理辨识和真实参数参考。报告最终位姿误差、成功率、动作数和耗时。基础规划的目标依然可能很容易；成功率都满分时，不能将预测改善自动说成任务能力提升。精确停稳任务需要先定义速度阈值和保持时间，并证明真实参数参考能完成，再单独评估。

## 第二阶段：从零历史开始，证明何时试探更好

当前每种方法先获得六次历史动作，这只能验证历史条件预测，不能证明机器人会主动收集信息。主动试探实验必须改成同一个初始状态、**零免费历史、相同总执行动作预算**。机器人为了了解物性而做的每一次推动，都计入总预算。

先实现一个可解释的版本。用多个可能的运动响应形成候选未来，对同一目标分别规划。如果不同响应假设下最优推法基本相同，则直接行动；如果最优推法明显不同，再评估一次小幅试推是否能减少后续的任务损失。试推动作也必须付出移动物体、耗时以及可能失败的代价。

三种独立训练种子的差异不自动等于物性后验或已校准的不确定性。首个原型可以用模型集分歧作为启发式，但必须验证它与真实决策错误是否相关；如果使用粒子或隐变量假设，需要给出观察后的更新规则。不能读取真实隐藏参数来决定是否试探。

至少比较：

- 被动适应：直接向目标推动，利用自然获得的历史更新判断。
- 固定试探：执行预先固定的短试推动作，再开始规划。
- 不确定性阈值试探：预测分歧超过阈值时试探。
- 任务相关试探：仅在分歧足以改变当前任务的最佳决策时试探。
- 在线物理辨识加规划：使用同样的动作和观测权限，允许从交互中更新参数。

“真实参数已知”的规划器仍只作为上界参考，不与其他方法混为同信息条件的公平对照。所有阈值、试推动作和预算在开发数据上确定，之后锁定到独立评估。学习方法可以在更快决策或更少交互上有价值，但不能通过削弱物理基线来制造优势。

这一阶段的核心图不应只是预测曲线，而应是**成功率—总动作预算曲线**：在预算紧张时，选择性试探能否比固定试探少花动作，又比直接推更可靠。同时报告每回合试探次数、总耗时和最终误差。如果固定试探或物理辨识已经达到同样表现，应如实将结论定为“此任务下主动选择尚无收益”，再决定是否增加有科学依据的任务复杂性。

## 第三阶段：完成可解释展示，再接真实视觉输入

先用已有状态模型做清楚的三联屏：左侧直接推、中间固定试探、右侧任务相关试探。三者共享初始任务和物性，每个方法从自己的真实执行中获得历史。同步展示执行前的未来预测、执行后的实际轨迹，以及试探后预测发生了什么变化。加入全部场景选择和固定首例，失败案例同样可看，不能只保留获胜场景。

当第二阶段有明确结论后，再加入图像编码：从低分辨率图像估计对象表示，学习动作条件未来，比较状态输入上界、图像输入模型和感知误差。训练和评估按整回合、对象外观或场景拆分，避免相邻视频帧跨集合。更换目标时复用同一动力学模型并重新规划，是适合现场展示的能力检验。

目前页面是预测状态渲染，加入图像编码也不自动等于视频生成。只有训练并评估未来图像输出后，才称为视觉生成世界模型。任务模型小而透明不妨碍形成本科论文；可靠实验、真实能力差异和明确边界比网络参数量更重要。

## 十周内如何安排

优先在接下来的数日完成第一阶段的可重复结论。第一至二周完成主动试探最小原型和去留判断；第三至五周完善算法、强基线与锁定后的主实验；第六至七周做必要的视觉输入与演示集成；第八至十周集中论文、复现实验和答辩材料。实际排期应服从前两阶段结果，不预先承诺大模型或多物体场景全部完成。

若长期预测始终无法支持更好决策，应及时把题目收窄为“历史条件动力学预测与规划系统”，或比较学习模型和物理辨识的精度—计算成本折中。若主动试探产生稳定收益，则围绕“试探何时值得”组织论文贡献。两种结论都应保存代码、配置、原始结果和 GitHub 提交，避免只保留漂亮截图。
