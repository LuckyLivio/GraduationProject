# 对象交互世界模型：从绕障走向“先试探，再想象，再推动”

检索日期：2026-09-17。本文是升级方向研究，不是新系统已实现或实验已成功的声明。原始访问状态、来源摘录和响应 SHA-256 见 [interaction-sources.json](../artifacts/research-upgrade/interaction-sources.json)。本轮阅读了原论文摘要、可访问全文和作者代码说明；不声称穷尽所有最新工作。

## 建议结论

最适合当前资源的升级是：**外观相同、动力学不同的货箱，由机器人通过少量接触了解其运动响应，在世界模型中比较多个推法，再把货箱推入指定位置。** 画面中同时显示“直接推”“先轻推再重新规划”“采用不同接触位置”的未来演化。用户能看到箱子的位置、方向、是否撞击其他箱子、是否越过禁区，而不是只看一条小幅变化的轨迹。

建议题目为《面向未知物体动力学的交互式世界模型与推物规划研究》。10 周内先做二维真实接触仿真和 2.5D 展示。自主训练小型动作条件对象动力学模型；图像编码器是第二阶段选项。利用结构化状态训练也属于学习世界模型，但必须写清传感输入和已知几何，不能包装成从原始图像端到端学习。

这个升级的展示潜力明显强于现有单机器人阻尼场，但**“主动试探 + 世界模型 + 规划”已有明确先行工作**。可以形成完整、有技术含量的本科研究；不能在实验前承诺“巨大算法创新”或强基线面前的巨大优势。

## 为什么这个任务更能说明世界模型的作用

现有导航场景里，控制任务往往不需要准确预测很远；几种方法都能到终点。推箱任务中，动作会改变环境本身，且接触位置、力度、摩擦、箱子之间的碰撞会造成明显不同的后果。例如绕到箱子另一侧轻推可以入位，直推可能碰到禁区，重推可能把相邻箱子一起带偏。

推荐演示同时包含三层证据：

1. **同动作、同初始历史的预测回放：**播放模型预计的物体位置和真实结果，显示接触前后及长时误差。模型看不到未来真值。
2. **同局面、多个候选动作的未来：**显示各方案的预测结果、风险和目标代价，再执行选择的动作。未经执行的分支应标为“模型预测”，不能画成已验证事实。
3. **同种子闭环对比：**冻结模型、在线上下文模型、强系统辨识控制器同场景并排运行；展示成功、失败和探测成本。所有方法都可能成功，全部结果都保留。

演示可以挑选有解释性的案例，但必须另有预先固定的测试集。不能只给学习模型记忆隐藏物性而不给基线历史，不能通过削弱物理模型来制造差距。

## 自己训练什么

第一版控制观察采用可解释的对象状态：推杆与 1–3 个箱子的位置、朝向、速度、尺寸、历史动作。**质量、摩擦、接触参数仅留在仿真器中，不输入控制器。** 训练目标是未来对象状态，不要求网络直接输出可辨识性存疑的“真实质量”。

建议采用对象图动力学网络与小型 GRU 上下文编码器：历史交互编码为动力学上下文，图网络根据当前对象、接触关系和动作预测下一步状态增量。通过 3–5 个随机初始化成员估计预测差异，使用多步展开损失减少滚动误差。接触信息若由仿真器提供，必须作为额外传感通道公开说明；更干净的第一版仅由已观察几何推断潜在接触边。

建议首轮控制在 1–3 百万参数以内，采集 10 万至 30 万条含接触转移，先使用状态级模型。**这是拟定的工程预算，不是论文提供的训练成本或已经测得的可行性。** 在本机 16GB 显卡上先跑 1,000 次更新，记录峰值显存和每秒样本数，再决定批量、模型和总训练量。不要把无接触静止帧当成大部分数据，否则损失很低但实际推不动箱子。

图像阶段可在动力学验证后增加 64×64/96×96 图像编码与对象追踪，并与使用结构化状态的上界比较。当前 10 周不建议同时从零攻克无监督对象发现、长视频生成、连续接触控制和真实机器人迁移。

## 物性可辨识性要先说清

两个静止、外观相同的物体，单张图像不包含足够信息辨别它们的质量。历史动作只有在能激发不同运动响应时才有信息。速度控制的准静态推动中，箱子位置可能主要由几何约束决定，质量未必能从位置轨迹中辨识；未知作用力和摩擦也可能相互混淆。

因此第一版需要明确采用**已知指令力/可观测推杆动力学、有加减速响应的动态推动**，或把任务表述为“在线学习可预测的动力学上下文”，不宣称恢复唯一质量。若只观察位姿且真实接触力不可见，应单独验证在所选动作范围内，两个不同物性模型是否产生可区分的观测。所有方法共享相同的动作和传感接口。

未知属性不等于学习模型自动胜过解析方法。只要真实动力学很简单，带正确结构的系统辨识 MPC 理应很强。必要时应承认这种基线胜出，论文转向样本效率、跨对象泛化或较复杂接触条件下的差异，不能刻意改坏基线。

## 可检验的本科创新候选

建议只选一个主问题：**有限接触预算下，是否应该先试探，以及什么时候停止试探。** 固定探测可能浪费时间或把箱子推到危险位置；纯信息增益可能了解很多与当前任务无关的参数。候选改进是用“不同动力学假设是否导致不同任务决策”作为探测触发条件，再从短而可恢复的候选探测中选择动作。

这与已有主动辨识、dual control、目标相关探索紧密相关，目前只能称为待验证的实现假设，不能先写成已证明的新理论。至少需要做“仅预测方差触发”“固定次数探测”“任务相关触发”三种消融，证明不是任何额外动作都有效。

## 48 小时的去留实验

### 第一天：先检查任务确实需要推理

实现一个推杆、一个有旋转的箱子、一个目标区和一个禁区。先不加入多箱连锁反应或视觉编码。用强解析接触模型和可访问真实参数的 oracle MPC 检查任务是否可控：如果 oracle 都不能完成，先修仿真与规划，不继续训练。

生成数据时随机化物性、接触位置、物体姿态、初速度，并保留试探/侧推/制动等动作。按完整物性组合与完整回合划分训练、验证、测试，禁止将同一个轨迹的窗口分散到不同集合。先训练无历史对象模型与历史上下文对象模型，检查同一初始状态下不同动作预测是否显著不同，并计算接触后的 5/10/20 步误差。

### 第二天：与强基线一起跑，而不是只拍演示

建议固定一个小型筛查集：40 个未见回合，其中 20 个为训练范围内组合、20 个为保留物性组合；使用 3 个模型训练种子。它只用于路线筛查，不作为最终论文的确认性测试集，后续必须另留全新测试种子。

| 方法 | 作用 |
| --- | --- |
| 几何/反馈推动 | 直观的无前瞻参考，不能作为唯一主要对手。 |
| 冻结物理 MPC | 参数采用训练集均值，衡量已知平均动力学。 |
| 在线 SysID-MPC | 利用同样历史、同样可见力/动作和状态估计质量/摩擦或有效参数；这是核心强基线。 |
| 固定低幅试探 + SysID-MPC | 防止主动学习的优势其实只是多了几次接触。 |
| 无历史学习世界模型 + MPC | 验证上下文记忆是否必要。 |
| 有历史学习世界模型 + MPC | 先测被动适应，不带主动探测改进。 |
| 固定试探/方差触发/任务相关触发 + 同一学习模型 | 核验探测策略的真实增益，主比较限制总动作数、接触力和控制时间预算。 |
| oracle 物理 MPC | 已知真实物性的上界诊断；明确这是额外信息，不混成公平基线。 |

主要指标应是目标区停稳成功率、碰撞/越界率、最终位置与角度误差、接触次数、完成时间和规划 P95 延迟。辅助报告相同动作序列的多步预测误差、物性上下文适应所需观察数。成功率按同一场景成对比较，模型种子分别报告；不能把 3 个模型在同一场景上的结果当成 3 个独立场景。

建议筛查门槛（仅是待预注册的项目决策阈值）：

- oracle 在筛查集达到至少 85% 成功，说明任务可控且规划器有用；否则先修任务。
- 有历史模型在保留组合的接触后 10/20 步预测误差，相对无历史模型至少下降 25%，并且行动条件敏感性检查通过；否则暂不投入大界面与视觉模型。
- 主动方案相对无主动方案在相同总预算下，要么成功率提高至少 15 个百分点，要么成功相近而接触/碰撞成本明显下降；对固定试探也要有增益。40 个回合仅筛查，不据此声称统计确证。
- 若强 SysID-MPC 同样解决任务，或主动探测收益只能靠额外预算获得，则放弃“世界模型巨大控制优势”的说法。保留世界模型交互展示价值，重新选择有证据支持的研究问题。

最终论文实验应重新冻结阈值、动作代价、数据集与种子，扩大到至少数十至上百个独立布局/物性组合，再报告置信区间、失败案例和公平计算预算。具体规模根据首轮耗时决定，不能把计划写成已完成结果。
