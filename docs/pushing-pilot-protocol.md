# 推物路线首轮开发筛查协议

2026-09-17。用户授权“先试一下”。此轮验证环境、自己训练的模型及基本规划，不提前宣称主动试探算法成立。

## 任务与信息权限

独立 Pymunk 刚体接触环境，一块 0.50×0.36m 矩形，固定质量 1。隐藏参数是速度衰减、接触摩擦和质心偏移；先用相同状态/动作测参数敏感性，不将质量作为待推断目标。

状态观察为几何中心位置、角度、线速度和角速度。宏动作指定物体哪一侧、沿边偏移和推杆速度；推杆可重定位，然后推进 0.30s、脱离后滑行 0.20s。此抽象不模拟机械臂绕行，不是标准 PushT；无视觉感知或视频生成。图像来自预测状态渲染。

所有方法共享精确状态观察、已执行动作、最多最近 6 次转移。学习模型不读物性标签；物理辨识仅从同样历史拟合参数。oracle 读真实参数，只是有额外信息的参考。候选评估不执行真实环境。

## 数据与训练

- 训练：1,200 回合×20 步；验证：120 回合×20 步。整回合与参数独立抽样，种子起点 52000 / 62000。
- 开发筛查：40 回合×20 步，种子起点 71000；前 20 个训练参数范围内，后 20 个衰减/质心范围外。这是开发集，不是最终论文测试集。
- 训练范围：damping [0.10,0.80]、friction [0.15,0.95]、局部质心偏移各 [-0.06,0.06]m。域外：damping 0.05 或 0.90、局部 x 质心 ±0.07m。
- 模型：无历史 MLP 与 GRU 历史条件 MLP。局部坐标处理平移/旋转不变性；学习完整宏动作之后的运动变化。历史特征为过去的观察、动作、后续观察，不含未来转移。
- 第一轮每种模型 3 个随机种子：17、29、43；最多 2,000 次梯度更新，batch 512。仅用验证一步误差选 checkpoint。数据量/网络比此前提议缩小，目的是尽早测出实际收益与代价。
- 冻结真实历史后开放展开，想象的转移不作为新的物性辨识证据。记录参数数、更新数、损失、吞吐、训练时间、显存和文件哈希。

## 比较与指标

固定每个开发回合第 6 步为预测起点，比较未来 1/5/10 个宏动作：无历史模型、有历史模型、静止/匀速、同历史在线物理辨识。报告位置 RMSE、角度 MAE、角速度误差，逐回合留痕；三个模型种子不能把 40 个场景变成 120 个独立场景。另测打乱历史的模型及改变动作是否导致正确预测差异。

基础规划用同一目标代价、候选动作、实际宏动作预算比较 learned/no-history、learned/history、SysID 与 oracle。先验证可控性，闭环开发面板可以小于 40，但报告实际数量与选择规则，不能把固定回放个例说成总体优势。禁止为了得到想要的差距削弱物理辨识。

这一轮尚不训练策略网络，不实现任务相关主动试探算法，不以额外试推动作后的改善声称主动规划创新。若预测和闭环可用，再做固定试探与选择性试探的独立实验。
