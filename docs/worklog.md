## 2026-09-17 · 从选题进入可运行验证

用户确认：智能科学与技术本科，约 10 周后答辩；展示偏好为“机器人预见未来”，技术要求为智能方法及可论证的创新。今天先完成小系统并启动关键对照，尽早判断选题是否可行。

### 本日协议

- 真实 2D 运动环境，3 个移动障碍；固定未知空间阻尼场，域外测试仅将强度乘以 1.7。
- 第一版采用**混合动力学世界模型**：3 个小型 MLP 从交互转移推断阻尼，已知的动作积分和障碍反弹规律保留。这是为了快速验证而收缩的实现，不能称为端到端学会整个环境。
- 先学习位置相关阻尼，模型推理不调用环境的真实阻尼函数；简单全局物理模型和近期历史局部辨识模型作为强对照。
- 自适应机制只调整预测视野；固定短/中/长视野、探测成本与候选预测预算全部记录。
- 训练、验证、预测测试、规划器验证、导航测试使用独立种子来源。先用规划器验证回合确定固定视野参照，再评估测试集。
- 今日首轮只有一个独立训练运行，3 个集成成员不等于 3 个独立实验种子；结果仅用于可行性诊断。后续改参数不能再把这批诊断种子当最终论文盲测。
- 显示真实预测与执行记录。交互界面当前为可回放实验，实时推理入口可在此基础上增加。

### 与早期计划的差异

第一版未使用 5 步历史 MLP，也未端到端预测全部状态；冻结的学习模型只输入当前位置，物理辨识基线读取过去转移。这一不对称给予物理基线更强的在线适应能力，需要明确报告。仅在先导实验确有需求时增加历史模型；不把该修改提前当作完成。

控制周期为 0.15 秒，最大 100 步，视野集合为 5/10/16 步。模型在 CPU 上训练和执行以减少小批量 GPU 同步开销；已检测 GPU 可用，但不凭设备名称推断实时性能。
